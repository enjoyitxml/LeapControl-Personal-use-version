> v2.6.0 和 v2.6.1 只隔一天，很多人的行程、充电那批改动还没装上。这里把两版合在一起说明，
> 免得只看到「修了个图标」以为这次没什么。

### 本次更新（v2.6.1）：桌面小组件

- 右上角的状态提示文字和刷新键，颜色改为**跟随「字体颜色」**，默认都是白色。
  以前提示文字走一条单独的「高亮色」（全透明版式下是绿色）、刷新键是半透明白灰，
  改字色时这两处不跟着变
- 各种状态前面加了一颗小图标，不用读字也认得出：
  - 充电中 → 闪电；已充满 / 充电完成 → 满格电池
  - 车辆已解锁 → 开锁；后备箱、车窗、空调、电池预热、遮阳帘、哨兵各用自己的图形
  - 控车成功 → 对勾；控车失败、登录已失效 → 感叹号；未登录 → 人像
  - 正在同步 → 循环箭头
- 「12:30 更新」「尚未同步」这类时间提示**不加图标**，保持干净
- 多项同时开着时只显示第一条（例如「哨兵已开启 · 等3项」），图标跟着第一条走
- 「个性化 → 桌面小组件 → 颜色与背景」里去掉了「状态提示高亮色」——提示色已改跟字色，
  这一项不再生效，留着只会让人调了没反应

### 随 v2.6.0 一并发布（很多人还没装上）

**行程记录**

- 首页行程条重做：跑起来是一条实时车速曲线，下面配一行行驶节奏摘要
  （走了多久、停了几次、堵了多久、平均车速），开与不开都有明确反馈
- 行程记录中的二级页面，实时面板默认展开，可直接看到这一段的速度、里程、耗时、能耗；
  面板可以手动收起，收起后下次进来仍是收起的
- 行程新增**续航达成率**：实际行驶里程 ÷ 表显掉的续航，记录中的和已完成的行程都会显示

**充电**

- 充电历史改成**按时段查看**：顶部「近 7 天 / 月 / 年」，选「月」可以指定具体哪个月、
  选「年」可以指定哪一年；上方一张大数字卡显示这段时间充了多少度、充了几次，
  下方是分布柱状图（近 7 天按天、按月按天、按年按月）
- 充电记录新增**表显续航变化**：充前、充后各是多少，一共涨了多少公里

**账号与登录**

- 「我的」页点头像卡，可以查看登录账号与完整车架号（等宽字体，报故障、找客服时照着念）
- 登录已过期时直接给「重新登录」按钮，点了就跳登录，不再只弹一行提示

**外观**

- 桌面图标：方向盘图形缩到与零跑官方 App 图标同一体量，不再显得比官方图标大一圈
