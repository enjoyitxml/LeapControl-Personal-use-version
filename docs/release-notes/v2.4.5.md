### 新增

- 定时空调新增「到点联动」：到点开空调的同时，按勾选再关车窗、关遮阳帘、开车内座椅加热 / 通风、开方向盘加热
  - 配置只存本机，到点由手机发控车指令；空调本身仍由车端执行
  - 执行完给一条通知，告诉你哪几项成功了
  - 重启手机 / 覆盖安装后自动重排闹钟
- 定时空调的开启时间从「时 / 分」下拉换成滚轮，与充电时段一致，每滚过一格给一次轻触感

### 修复

- 充电上限改成 50–100（原来锁在 80 起）
- 打开健康充电时，上限如果已经是 100 会自动降到 90，并提示一句
- 健康充电开着时把上限拖到 100，会被吸到 95 并提示；关掉健康充电才允许拉满
- 关掉健康充电会同时下发「上限 100」，避免上次设的 90 一直压着，看起来像关不掉
