### 新增

- 自定义壁纸下，文字会跟着背景自动反色：深色壁纸配浅字、浅色壁纸配深字，换壁纸不用先去改明暗模式
  - 壁纸上那层薄纱也跟着换，深字配白纱、浅字配黑纱，两边一起拉对比
  - 个性化 → 主题与背景 → 「文字随壁纸反色」可以关掉，关掉后完全跟随明暗设置
  - 以前设过的壁纸会自动补算一次亮度，不用重新上传

### 修复

- 首页控车按钮下面那排小字（解锁 / 上锁 / 后备箱 / 车窗）压在壁纸上太淡，换成更实的一档文字色并叠一层反向柔光
- 从首页车辆位置卡进入找车页时，车端驻车照片会重新取一次，不再停在上一趟停车缓存的那张
- 哨兵模式不再按车型判断「有没有这个功能」，没上报状态的车型也能添加这颗快捷按钮并下发指令
- 玩法说明「零记」一节不再提「我的 → 意见反馈」，该入口已下线
