### UI 调整
- **「设置」与「个性化」按用途重新分组**，从一长串卡片变成有标题的几段，找东西不用再从头扫到尾
  - 设置 = 怎么运行，六段：**车辆**（车名 / 动力 / 车模图）→ **控车与安全**（密码 / 二次确认 / 蓝牙钥匙）→ **快捷入口**（再点一次 / 回顶按钮 / 控制中心磁贴）→ **数据与备份**（零记、语音、两套数据的导出与找回）→ **地图与目的地**（高德 Key / 搜地点 / 驻车拍照）→ **高级设置**（折叠：电池容量 / 帧率 / 日志）
  - 个性化 = 看起来怎样，四段加两组：**主题与背景**（明暗模式 / 主题壁纸 / 相伴卡背景 / 换壁纸的方式）→ **首页**（车模外观 / 页面布局 / 右上角图标）→ **零记**（灵感球位置）→ **桌面小组件** → **应用图标**
- **外观相关设置集中到「个性化」**：原「设置 → 首页外观」里的换壁纸方式（点击 / 小白点 / 关闭）与两个小白点开关整体搬到「主题与背景」，设置页只留运行相关的项
- **零记与行程的备份合并成一张「备份与找回」卡**：卡内用小标题分开两套数据，丢数据时只需要记一个地方；零记卡只留「启用零记」与语音识别
- **桌面小组件设置拆成五块**：版式 / 控车按键 / 大小 / 颜色与背景 / 放到桌面，不再挤在一张超长卡片里
- 每个分组都带一行说明，卡片标题与分组标题不再重复堆叠
- 首页**车名不再限死宽度**，改为吃满右侧图标以左的全部剩余空间：同样的字号能多显示三四个字，宽屏更多、窄屏自动收，切换车辆的箭头不会被长名字挤走

### 修复
- **桌面小组件短时间连发两条指令不再"假成功"**：此前点完解锁紧接着点开后备箱，卡片立刻写「后备箱已开启」，车其实没动 —— 那是网关受理回执被当成了车端执行结果。现在受理瞬间只说「开后备箱已下发」（按键仍立即高亮，表示已发出），随后在后台回读车况求证：车端真的开了才写「后备箱已开启」，到最后仍没动就写「后备箱还没开」并标警示色，读不到该信号则不作声
- **两条指令不再并发出门**：连续点不同按键时，第二条会先等上一条落地（间隔 2.5 秒）再下发，避免车机刚被唤醒时后一条被丢掉；解锁 / 上锁 / 鸣笛 2.5 秒内重复点击不再重复下发，连点两下不会出现「开 + 开」
- **同按键连点不再被误判成反方向**：等待下发的那一秒多里再点一次，此前会算出「开完立刻关」，两条指令互相抵消，看起来像「按了没反应」；现在统一提示「正在执行，请稍候」
- **卡片提示不再闪烁回退**：点击、提示到期、刷新三条并发重绘会让旧帧盖住新帧（写了「调节中」又闪回「已解锁」）；同时前一轮的事后求证醒来后会覆盖后一次动作的提示
- **行程轨迹图上的假折返剪掉**：采样点偶尔漂出去一两百米（地库口、高架下、刚唤醒的车机），或导航补线时为了「合法到达」绕一个街区，画出来就是一个大圈又绕回原路，车其实没掉头。现在先剔除采样尖刺，再按表显里程预算判断：绕行超出了表显里程才剪环，车真绕了路的那一段里程里含得下，会照旧保留；读不到表显里程时从严，只剪 400 米以上的大环
- 轨迹修正只改**画出来的线**，采样点、里程、时长、能耗与起终点地址一律不动，旧行程也会按新规则重画
