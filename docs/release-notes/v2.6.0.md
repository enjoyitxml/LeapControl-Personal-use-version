### 新增

- 首页行程条重做：跑起来是一条**实时车速曲线**，下面配一行行驶节奏摘要（走了多久、停了几次、堵了多久、平均车速），开与不开都有明确反馈
- 行程记录中的二级页面，**实时面板默认展开**，可以直接看到当前这一段的速度、里程、耗时、能耗；面板可以手动收起，收起后下次进来仍是收起的
- 行程新增**续航达成率**：实际行驶里程 ÷ 表显掉的续航，记录中的行程和已完成的行程都会显示（首页指标行、行程卡、明细里都有）
- 充电历史改成**按时段查看**：顶部「近 7 天 / 月 / 年」，选「月」可以指定具体哪个月、选「年」可以指定哪一年；上方一张大数字卡显示这段时间充了多少度、充了几次，下方是分布柱状图（近 7 天按天、按月按天、按年按月）
- 充电记录新增**表显续航变化**：记录充前和充后的表显续航，以及一共涨了多少公里；上方汇总也会给出这段时间续航总共涨了多少
- 「我的」页点头像卡，可以查看**登录账号与完整车架号**（等宽字体，报故障、找客服时照着念）
- 桌面图标：方向盘图形缩到与零跑官方 App 图标同一体量，不再显得比官方图标大一圈

### 修复

- 登录已过期时只弹一行提示，点不掉也不会引导 → 现在直接给「重新登录」按钮，点了就跳转登录
- 登录失效的提示曾经显示成带对勾的绿色成功样式，现在按错误样式上色
