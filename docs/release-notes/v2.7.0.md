### 蓝牙钥匙

- **连接假死自愈**：车机蓝牙偶发「连上了、但服务发现一直没回音」，以前只能断开重来。
  现在会自己释放这条链路、跳过 MTU 协商再连一次，只重试一次，还不行才报错。
  跳过 MTU 是因为假死多半就卡在这一步，再协商一次会原样卡死
- **扫描被系统限流时退避**：短时间内反复扫描会被系统罚停（errorCode=6），
  以前照样按原节奏重试、越试越糟；现在退避 30 秒再继续待命
- 扫描失败提示改成具体原因（上一轮扫描尚未结束 / 应用注册失败 / 系统内部错误 /
  硬件资源耗尽 / 被系统限流 等），不再统一一句「蓝牙扫描失败」
